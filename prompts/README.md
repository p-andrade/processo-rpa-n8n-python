## 📌 Visão Geral

Este diretório reúne os prompts e templates utilizados tanto para configurar o **Agente de IA Generativa (`Message a model` — GPT-4o)** dentro do workflow do n8n quanto para usar copilotos de IA no desenvolvimento, auditoria e evolução da automação:

| Arquivo | Finalidade |
| :--- | :--- |
| 🌟 **[`prompt-final-desafio-dio.md`](./prompt-final-desafio-dio.md)** | **Prompt Principal do Assistente de Investimentos:** contém a especificação completa do prompt de e-mail financeiro com compliance (zero promessa de ganho) e o prompt arquitetural do pipeline RPA + n8n. |
| [`prompt-design-workflow.md`](./prompt-design-workflow.md) | Template estruturado para projetar novos workflows de cruzamento de dados e RPA no n8n. |
| [`prompt-geracao-conteudo.md`](./prompt-geracao-conteudo.md) | Template para geração de mensagens e relatórios financeiros personalizados com saída JSON estrita. |
| [`prompt-troubleshooting.md`](./prompt-troubleshooting.md) | Template para diagnosticar e corrigir erros em nós `Code`, `Merge`, `OpenAI` e `If` do n8n. |
